# OpenCode skills bundle (adapted)

This folder contains three skills and two commands, rewritten for satellite telemetry anomaly detection. The original repository's RDMA/Kubernetes-specific claims, lab paths, figure issues and author details have been removed.

Install by copying the `.opencode` directory **inside the LaTeX repository root**, next to `main.tex`. Place the accompanying `AGENTS.md` in that same root if not already present.

These files are collaboration instructions; they do not automatically add tools, execute code, or register as native ChatGPT skills. In ChatGPT, add the files as project sources or provide them when requesting a chapter review. On an OpenCode-compatible setup, the skill/command directories are laid out conventionally.
